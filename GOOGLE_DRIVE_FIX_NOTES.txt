FinanceOne Google Drive 연동 수정 내용

수정 파일:
- android/app/src/main/java/com/financeone/mobile/FinanceOneGooglePlugin.java

변경 요약:
- 기존 AccountPicker + GoogleAuthUtil.getToken() 방식 제거
- Google 공식 AuthorizationClient 방식으로 변경
- 요청 범위:
  - https://www.googleapis.com/auth/drive.appdata
  - openid
  - email
  - profile
- 권한 동의가 필요한 경우 GoogleAuthActivity를 통해 PendingIntent 승인 화면 실행
- Drive appDataFolder의 FinanceOne-data.json 업로드/다운로드 로직 유지
- UnregisteredOnApiConsole / DEVELOPER_ERROR 발생 시 Android OAuth Client 패키지명/SHA-1 확인 안내 메시지 강화

Google Cloud Console에서 필요한 값:
- OAuth Client 유형: Android
- 패키지명: com.financeone.mobile
- SHA-1: 현재 설치 APK의 실제 서명 SHA-1
- 테스트 사용자: kjkjkj100001@gmail.com
- 데이터 액세스 범위: .../auth/drive.appdata 포함
- Google Drive API 사용 설정 필요

빌드 방법:
1. ZIP 압축 해제
2. FinanceOneMobile 폴더에서 npm install
3. npx cap sync android
4. cd android
5. gradlew.bat assembleDebug

주의:
이 환경에서는 Gradle 배포 파일 다운로드가 막혀 APK까지 빌드 검증하지 못했습니다.
수정된 원본 프로젝트를 Windows/Android Studio에서 빌드하세요.
